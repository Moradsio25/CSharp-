# CSharp Daily LeetCode Solutions

This repository is a personal C# sandbox for solving LeetCode daily challenge problems in a clean, reusable format.

## Structure

- `src/LeetCodeDaily` - .NET console project for daily solutions
- Each problem is implemented as a small, focused class and can be expanded with tests or notes.

## Daily challenge

The first solution added is:

- `Problem 1524: Number of Sub-arrays With Odd Sum`

## Run locally

```bash
dotnet run --project src/LeetCodeDaily/LeetCodeDaily.csproj
```

## Notes

This repo is meant to grow over time with one daily solution at a time.
